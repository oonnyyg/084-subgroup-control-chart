# 子组均值-极差控制图分析

纯标准库实现的生产测量批次分析工具。以每条产线各自的基线批次建立
X-bar（均值）与 R（极差）控制限，再对后续监测批次进行越界判定与
连续偏移（运行规则）识别。不绘图。

## 用法

```bash
python -m process_chart INPUT.json OUTPUT_DIR
python -m unittest discover -s tests
```

输入为 JSON 文件，输出目录不存在时自动创建。任一输入非法时进程以
非零状态退出，并且**不创建任何报告文件**（先整体校验、分析，再落盘）。

## 输入格式

顶层可以是产线数组，也可以是 `{"lines": [...]}` 对象：

```json
{
  "lines": [
    {
      "line_id": "A1",
      "baseline": [
        {"batch_id": "B1", "values": [9.8, 10.1, 10.0, 9.9, 10.2]}
      ],
      "monitoring": [
        {"batch_id": "M1", "values": [10.0, 10.1, 9.9, 10.0, 10.0]}
      ]
    }
  ]
}
```

校验规则：

- `line_id` 为非空字符串且全局唯一；`batch_id` 在同一产线内唯一。
- 每批 `values` 必须恰为 5 个有限数值（不接受 `NaN`、`Infinity`、
  布尔值、字符串）。
- `baseline` 至少 2 批；`monitoring` 可为空数组或缺省（按空处理）。
- 批次按输入顺序处理，不做任何重排。

## 统计口径

每批计算：

- 均值 `mean = (x1 + ... + x5) / 5`
- 极差 `range = max(x1..x5) - min(x1..x5)`

控制限**只由基线批次**估计，不剔除任何“异常”基线点，也不混入监测数据：

- 均值中心 `X̄̄ = 基线各批均值的平均`
- 平均极差 `R̄ = 基线各批极差的平均`
- 均值控制限：`X̄̄ ± A2 * R̄`，其中 `A2 = 0.577`（子组大小 n=5）
- 极差中心：`R̄`；极差下限 `D3 * R̄ = 0`；极差上限 `D4 * R̄ = 2.114 * R̄`

### 限值边界（重要）

- 只有**严格越过**限值才算越界：均值 `< LCL` 或 `> UCL`、极差 `< LCL`
  或 `> UCL`；与限值**相等不算异常**。
- `R̄ = 0` 时不做任何特殊放宽：极差上限即为 0，任何非零极差都严格越界。

### 均值序列运行规则

运行规则只应用于**监测批次的均值**，基线不参与滑窗。规则在窗口末批
记录，所有重叠窗口逐一保留：

- `same_side_8`：连续 8 批均值严格位于中心同一侧；任一均值恰好等于
  中心则在该处中断（等值既不属于上侧也不属于下侧）。
- `trend_up_6`：连续 6 批严格递增；`trend_down_6`：连续 6 批严格
  递减；相邻两值相等则趋势中断。

每条命中记录其规则名及窗口起始/结束批号，并挂在结束批上；同一末批
可以同时命中多条规则。

## 输出

- `line_<line_id>.csv`：每条产线一个文件（`line_id` 中非字母数字字符
  替换为 `_`），保留基线在前、监测在后的输入顺序，列为：
  `phase, batch_id, value1..value5, mean, range, mean_beyond_limit,
  range_beyond_limit, run_rules`。其中 `run_rules` 为该批作为末批命中
  的规则，格式 `规则:起始批:结束批`，多条以 `;` 分隔。
- `summary.json`：各产线控制限、五类规则命中次数
  （`mean_beyond_limit`、`range_beyond_limit`、`same_side_8`、
  `trend_up_6`、`trend_down_6`）、运行规则明细、异常监测批 ID，以及
  全局合计。

“异常监测批数”统计**至少命中一条规则**（含均值/极差越界）的监测批；
同一批命中多条规则只计一次。
